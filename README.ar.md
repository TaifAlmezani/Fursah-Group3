# تطبيقات اليوم الثالث

يضم المستودع مشروعين تعليميين مستقلين:

| المشروع | الهدف | نقطة البداية |
|---|---|---|
| مساعد الصيانة بالذكاء الاصطناعي | دراسة حالة للمدرب؛ اتبع تعليمات التشغيل والتحقق الخاصة بها. | [دليل الصيانة باللغة الإنجليزية](ai-maintenance-assistant/README.md) |
| فرصة FURSAH | تمرين لبناء الخادم، مع واجهة React وعقد API وبيانات تدريبية خيالية جاهزة. | [دليل فرصة](fursah-starter/README.ar.md) |

## ابدأ بمشروع فرصة

اتبع [دليل فرصة](fursah-starter/README.ar.md) بالترتيب: تجهيز البيانات، ثم تنفيذ الخادم، ثم ربط الواجهة. تتضمن الحزمة 1,000 إعلان خام خيالي وواجهة جاهزة وهيكل API. البحث والتفاصيل تمرين ينفذه المتدرب؛ لا يوجد وضع تجريبي أو توصيات وهمية.

لكل مشروع إعداداته واعتمادياته المستقلة. نفّذ الأوامر من المجلد المحدد في دليله. يحتفظ المتدرب بتنفيذ اليوم الثالث عند الانتقال إلى مواد اليوم الرابع التي يقدمها الفريق المسؤول؛ راجع [تعليمات الانتقال](fursah-starter/README.ar.md#day4).
