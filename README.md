# Day 3 implementation

This repository contains two independent teaching projects:

| Project | Purpose | Start here |
|---|---|---|
| AI Maintenance Assistant | Instructor case study. Follow its own setup and verification instructions. | [Maintenance guide](ai-maintenance-assistant/README.md) |
| FURSAH — فرصة | Student backend exercise with a supplied React frontend, API contracts and fictional training dataset. | [FURSAH guide](fursah-starter/README.md) |

## Start with FURSAH

Follow the [FURSAH guide](fursah-starter/README.md) in order: prepare data, implement the backend, then connect the frontend. The package supplies 1,000 fictional raw announcements, a finished interface and an API shell. Discovery and details are student exercises; there is no demo mode or pretend recommendations.

Each project has separate configuration and dependencies. Run commands from the directory named in its guide. Keep your completed Day 3 implementation when adding the materials supplied by the Day 4 team; see the [handoff instructions](fursah-starter/README.md#continue-to-day-4).
