# Frontend — AI Maintenance Request Assistant 💻

واجهة مستخدم عربية تفاعلية (RTL) مبنية باستخدام **React + Vite + TypeScript**.

---

## 🚀 التشغيل السريع (Quick Start)

```bash
# 1. نسخ ملف الإعدادات
Copy-Item .env.example .env

# 2. تثبيت الحزم
npm install

# 3. تشغيل الواجهة
npm run dev
```

الرابط الافتراضي: `http://localhost:5173`

---

## ⚙️ المتغيرات البيئية (.env)

* `VITE_API_BASE_URL`: بادئة API (افتراضيًا: `http://localhost:8000/api`). الواجهة تضيف `/maintenance/requests` ومسار الاستكمال.
* `VITE_USE_MOCK`: `false` للاتصال بالـ Backend الفعلي، أو `true` لاستخدام بيانات تجريبية وهمية.

---

## 🎯 دور الواجهة في النظام
الواجهة تلتزم بمبدأ **العرض فقط (Presentation Layer)**:
* استقبال مدخلات المستخدم وإرسالها للـ Backend.
* عرض مسار المعالجة خطوة بخطوة (Trace Steps).
* عرض أسئلة التوضيح عند وجود نقص في البيانات والسماح للمستخدم بالرد لاستئناف المسار (Resume).

## الاختبارات

```powershell
npm run build
$env:BACKEND_PYTHON='C:/path/to/python.exe'
npm run test:e2e
```

Playwright يشغّل API فعليًا على 8018 وواجهة اختبار على 5178، مع قاعدة مؤقتة وheuristic ومتجهات مضبوطة معلنة. ما يستخدم قاعدة المستخدم، ولا يُعد إثباتًا لسلوك ASL أو embeddings الحقيقيين. هذه لها اختبار قبول مستقل حسب [معايير التحقق](../docs/TESTING.md).

## تجربة الجوال والكمبيوتر

التصميم يحافظ على شعار ساعي وألوانه. على الكمبيوتر يظهر ملخص البلاغ ومسار التنفيذ بجانب مساحة العمل. على الجوال، زر «تفاصيل البلاغ» يفتح لوحة سفلية؛ يمكن إغلاقها بزر الإغلاق أو Escape مع استعادة التركيز. الأسهم تغيّر تبويب اللوحة، وTab يبقى داخلها. النموذج يدعم موقعًا اختياريًا منذ البداية.

تفاصيل التصميم وأدلة التحقق في [تحديث تجربة الصيانة](../docs/UI_UX_REFRESH.md).
